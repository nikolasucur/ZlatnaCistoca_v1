# 🤝 Doprinos razvoju – Zlatna Čistoća v1

Hvala na interesovanju za doprinos projektu!

## Kako se prijaviti

Pošalji email na **rfs.srbija@gmail.com** sa sledećim informacijama:
- Kratko predstavljanje i tvoje iskustvo
- Koje oblasti te interesuju (backend, frontend, baza, dizajn...)
- Link na tvoj GitHub profil ili portfolio

## Šta tražimo

- 🐍 Python / Flask developeri
- 🎨 Frontend developeri (HTML, CSS, JS)
- 🗄️ Baze podataka (SQLite → PostgreSQL migracija)
- 🔒 Sigurnost (autentifikacija, zaštita ruta)

## Pravila

- Sav doprinos ostaje vlasništvo autora projekta
- Saradnici dobijaju kredit u projektu
- Uslovi dalje saradnje dogovaraju se individualno

## Prijava buga

Koristi [GitHub Issues](../../issues) za prijavu grešaka.
